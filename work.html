FEATURED PROJECT

NCTX Bus Ticket Application

Python programming project

For one of my university projects, I created a bus ticket application using Python. The program lets users choose from different ticket options, calculates the cost and records simulated purchases using CSV files.

One part I focused on was making sure the program could deal with incorrect inputs. I used input validation and exception handling, then tested different selections to check how the program responded.

I also worked with purchase records and ticket prices. It was useful seeing how different parts of the program worked together, especially when testing and fixing errors.
